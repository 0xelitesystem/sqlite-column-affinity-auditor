sqlite-column-affinity-auditor

Paste CREATE TABLE DDL from any dialect. See the type affinity SQLite actually assigns each column, which literals silently change storage class on insert, whether a STRICT table would accept the declared type, and which columns are true rowid aliases.

Input

Any dialect. Comments and multiple statements are fine.

Each line is inserted as a text value. An empty line is a legitimate probe, the empty string.

Self test

Independent and unaffiliated. This page is not affiliated with, endorsed by, or connected to SQLite or the SQLite Consortium. SQLite is named here only as the subject being analysed.

The five affinity rules are reimplemented from the published SQLite datatypes specification, section 3.1 "Determination Of Column Affinity". No SQLite code is reproduced here. The behaviour encoded in the self test fixtures was measured against SQLite 3.50.4.

Everything runs in your browser. Nothing you paste leaves your machine. Single file, no network, no storage, no analytics. MIT licensed. Source from elitesystem.ai.
